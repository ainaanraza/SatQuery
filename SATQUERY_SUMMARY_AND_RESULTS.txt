1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
SatQuery AI is an interactive, multi-modal, agentic Vision-Language framework
specifically developed for the ISRO Remote Sensing AI Hackathon.

Rather than relying solely on a generic vision model, SatQuery combines:
1. Autonomous Agentic Orchestrator: Dynamically plans tasks, parses natural
   language intent, and invokes specialist remote sensing tools.
2. Deterministic Geospatial & Change Analytics: Memory-safe GeoTIFF windowing,
   optical-SAR alignment, and temporal change localization.
3. 7-Billion Parameter Multimodal Remote-Sensing VLM: RS-LLaVA-1.5-7B fine-tuned
   on BigEarthNet and remote sensing datasets, loaded in 4-bit precision for
   high-efficiency GPU inference.
4. Real-Time Glassmorphism Web GUI: Connected to the backend over secure tunnels.
5. Verifiable Evidence Graphs: Ensuring zero hallucinations by anchoring every
   answer to coordinate bounds, CRS transforms, and tool execution logs.


2. SYSTEM ARCHITECTURE & CORE MODULES
--------------------------------------------------------------------------------
1. Geospatial Ingestion Foundation:
   - Memory-safe GeoTIFF loading and windowed chunking via rasterio abstractions.
   - CRS and Affine transform parsing with sub-pixel alignment.

2. Autonomous Agentic Orchestrator:
   - Dynamic Planner, IntentParser, and Executor mapping natural-language queries
     into verifiable N-step tool execution trees.

3. Analytical & Geospatial Intelligence:
   - Tool-sets for Bi-Temporal Change Detection, Spatial Alignment, Bounding Box
     Localization, and Deterministic Optical/SAR Fusion.

4. Temporal Series Engine:
   - TemporalSeries abstractions for multi-epoch chronological alignment, persistent
     region tracking, and trend analysis.

5. Multimodal Reasoning & REST API:
   - Ingestion of co-registered SAR & Optical grids.
   - FastAPI REST server (/analyze, /analyze/{id}) with CORS and async job management.

6. Evaluation & Benchmarking Infrastructure:
   - Automated evaluation harnesses for public RS datasets (VRSBench, RSVQA, CDVQA),
     measuring BLEU, Precision, and Accuracy.

7. Security Hardening & Evidence Graph:
   - Absolute Integrity Rule enforcement (EvidenceGraph mapping every claim to raster pixels).
   - Prompt injection sanitization and memory boundary checks.

8. Interactive Mission Control Web GUI:
   - Glassmorphism Web Dashboard (index.html, style.css, app.js) with dynamic status
     polling, visual node tracking, and live JSON output viewer.


3. MULTIMODAL MODEL ARCHITECTURE
--------------------------------------------------------------------------------
- Base Model: llava-hf/llava-1.5-7b-hf (Vision-Language Transformer)
- Domain Adaptation: BigData-KSU/RS-llava-v1.5-7b-LoRA (LoRA adapter fine-tuned on
  BigEarthNet Sentinel-2 multispectral imagery and remote sensing VQA pairs).
- Quantization & Deployment: 4-bit NF4 quantization (BitsAndBytesConfig) running
  on GPU with ~5.5 GB VRAM footprint.
- Raster Conversion: Automatic multi-band GeoTIFF normalization into 3-channel
  RGB tensors with CRS preservation.
